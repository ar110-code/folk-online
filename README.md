# پروژه بازی استراتژی آنلاین (فلک آنلاین / Megagame V4)

## راهنمای اجرا:
1. مطمئن شوید Node.js روی سیستم شما نصب است.
2. وارد پوشه پروژه شوید و دستور زیر را اجرا کنید:
   `node server/index.js`
3. در مرورگر به آدرس زیر بروید:
   `http://127.0.0.1:3000`

پوشه docs شامل قوانین و نقشه‌های اصلی بازی است.
